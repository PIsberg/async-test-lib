# async-test-analysis (module)

`StaticPinningScanner` — an ASM pre-scanner that finds Loom pinning sites in compiled classes before
a test run. One class, one dependency.

This module's main code depends on nothing else in the project and nothing depends on it. Keep it
that way: both directions are enforced by `ArchitectureTest`. If it starts needing the runner or a
detector, that is a design question, not a dependency to add.

The one exception is test scope: `LibraryStateIsKeyedByIdentityTest` reads the library's and the
agent's class files as bytes and runs `IdentityHashKeyScanner` (test sources) over them, refusing a
map or set keyed by an identity hash however the hash got there (#803, #895). It lives here because
ASM may not leave this module. Run it with `-am` (`mvn -pl async-test-analysis -am test -Dtest=...`),
or it scans the jars last installed in `~/.m2` instead of the working tree.
