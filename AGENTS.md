# AGENTS.md

Orientation for coding agents. This file is intentionally a pointer, not a second source of truth.

**Read [CLAUDE.md](CLAUDE.md) first.** It is the map: module layout, build and test commands, where
guardrails live, and the logging conventions.

## The short version

- Three-module Maven reactor. `async-test-lib/` is the library, `async-test-agent/` the Byte Buddy
  agent, `async-test-analysis/` the ASM pinning scanner. `ArchitectureTest` enforces the boundaries.
- **Maven is canonical**; Gradle is a secondary developer build kept in lockstep. Change one, change
  both.
- Guardrails are generated by vibetags into each module's `CLAUDE.md` and `.claude/rules/`. Never
  hand-edit between `VIBETAGS-START` / `VIBETAGS-END` — the next compile overwrites it.
- Before you finish: `mvn verify` must pass. It runs Checkstyle, PMD, SpotBugs, Error Prone, the
  JaCoCo thresholds and japicmp, all of which fail the build. See
  [docs/QUALITY_GATES.md](docs/QUALITY_GATES.md).
- A test that fails intermittently is a detector finding, not flake. There is deliberately no
  automatic rerun.
